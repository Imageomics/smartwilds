# Citizen Science Images Heat Maps

This directory contains code for generating heat maps of animal density from citizen science image data.

## Branch Workflow
Work on citizen science heat maps should be done in the `citizen-science-heatmaps` branch.

## Data Sources
- Images submitted by citizen scientists visiting The Wilds Summer 2025

## Analysis Goals
- Generate spatial density heat maps from public observations
- Complement professional sensor data with community contributions
- Identify visitor-accessible areas with high animal activity
