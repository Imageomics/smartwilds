Assumptions
- Camera traps use filtered CSVs when present and treat each detection timestamp as event presence.
- Drone detections are assigned to the nearest camera-trap site within 200.0 m.
- Drone rows labeled 'person' or 'vehicle' are excluded so the study tracks animal presence only.
- Jaccard is computed only inside each site's true shared availability window.
- Shared availability is defined from actual event timestamps, not broad collection date ranges.
- Shared sites found: TW04, TW01, TW02, TW09, TW11, TW06
