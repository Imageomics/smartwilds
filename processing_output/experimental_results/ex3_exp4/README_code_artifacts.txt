Code Artifacts for Submission
=============================

exp3_code/
- build_drone_arrival_summary.py
  Builds the strict drone arrival summary used by Experiment 3.
- build_exp3_strict_tables.py
  Generates the strict Experiment 3 tables, including drone-integrated resource modeling outputs.
- plot_exp3_strict_aggregate.py
  Generates the strict Experiment 3 aggregate utilization figure.
- path_config.py
  Shared dataset/workspace path configuration used by the scripts.

exp4_code/
- build_exp4_camera_strict_trace.py
  Builds the strict Campaign 2 camera-only replay trace for Experiment 4.
- replay_engine.py
  Runs replay simulation over the trace for all policies.
- evaluate_replay.py
  Aggregates replay outputs into policy-level metrics.
- plot_replay_timeline.py
  Generates replay timeline figures.
- build_exp4_strict_summary.py
  Produces the strict Experiment 4 summary table.
- policies.py
  Defines the replay policies used by the engine.
- path_config.py
  Shared dataset/workspace path configuration used by the scripts.
