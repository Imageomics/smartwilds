# Camera Trap Heat Maps

This directory contains code for generating heat maps of animal density from camera trap sensor data.

## Branch Workflow
Work on camera trap heat maps should be done in the `camera-trap-heatmaps` branch.

## Data Sources
- Camera trap images from The Wilds Summer 2025 deployment

## Analysis Goals
- Generate spatial density heat maps showing animal distribution
- Identify high-activity zones
- Analyze temporal patterns
