Step 3: Monitor progress

# One-time status check
bash monitor_detections.sh

# Live monitoring (refreshes every 30s)
bash monitor_detections.sh --watch

# With error details
bash monitor_detections.sh --detail
What the jobs do
12 SLURM array tasks, one per camera (V100 GPU, 32GB RAM, 12hr each)
Each runs YOLO+SAHI detection → BioCLIP species classification → distance/angle estimation → GPS projection
Output: one CSV per camera in detection_results/
Annotated images saved alongside
Estimated time
The big cameras (TW09-CT02 at 90K images, TW02-CT01 at 61K) will take the longest. At ~1-2 images/sec on a V100 with SAHI tiling, expect roughly:

Small cameras (<1K images): ~10-30 min
Medium cameras (10K-40K): 2-6 hrs
Large cameras (60K-90K): 8-12 hrs

What the drone script does
Extracts every 30th frame (~1fps from 30fps video) using OpenCV
Runs YOLO+SAHI (640px tiles) on each frame
Classifies each detection with BioCLIP using the same 60-label set (species + genus + background)
Outputs per-video detection CSV + frame summary CSV (with is_blank flag)
Tracks blank frames for workload analysis
Once everything finishes
Run postprocess_detections.py on both camera trap and drone outputs (NMS + background filtering)
Convert to Darwin Core (camera traps + drones)
Merge all 5 modalities into unified cross-modal observation table
Ready for experiments
