# Documentation guidelines

Local copies of the standards the SmartWilds dataset cards follow, kept here
so they can be dropped into an agent's context or packaged as a skill (see the
[Agents](https://imageomics.github.io/smartwilds/agents/) pages).

| File | Source |
|---|---|
| `FAIR2_DRONES_README.md` | [Imageomics/fair_drones](https://github.com/Imageomics/fair_drones) overview |
| `FAIR2_DRONES_QUICKSTART_GUIDE.md` | FAIR² Drones checklist |
| `FAIR2_DRONES_TEMPLATE.md` | FAIR² Drones dataset card template, with YAML front matter |

The FAIR² Drones Data Standard is licensed CC BY 4.0. It extends the
[Imageomics dataset card template](https://imageomics.github.io/Imageomics-guide/wiki-guide/HF_DatasetCard_Template_Imageomics/)
and the [Hugging Face dataset card](https://huggingface.co/docs/hub/datasets-cards) conventions.
