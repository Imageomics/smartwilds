# Paper framing
Overarching aim is moving away from accuracy (e.g., precision, recall compared to expert annotation) to utility for the domain - moving beyond the question of "is this method good?" to "is this method useful for the domain?" - e.g., does it capture the relevant ecological patterns? does it provide insights that are not possible with other methods? does it enable new research questions to be asked? 
We are moving beyond creating another labeled dataset, to saying 'we have these tools to automatically annotate data, but how do we use them to answer ecological questions?' - this is a shift from a computer vision/data science perspective to an ecological perspective, which is the ultimate goal of this work.
We don't actually care if the automated annotation is perfect, we care if it is good enough to capture the relevant ecological patterns and provide insights that are not possible with other methods. We want to evaluate the utility of these methods for the domain, rather than just their accuracy compared to expert annotation.
Need to be precise in our framing of the problem and the contribution of our work - we are not just creating another labeled dataset, we are providing a methodology for using automated annotation to answer ecological questions, and evaluating the utility of this methodology for the ecological research questions.
A lot of time and effort has been spent on creating AI
models - need to actually start using them to answer ecological questions, and evaluating their utility for the domain, rather than just creating more models and datasets. We want to move towards a more applied perspective, where we are using these tools to actually do science, rather than just creating tools for the sake of creating tools.
