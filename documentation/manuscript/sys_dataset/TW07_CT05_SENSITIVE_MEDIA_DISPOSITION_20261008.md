# TW07-CT05 Sensitive Media Disposition

## Evidence

The retained `TW07-CT05` directory contains only `metadata.txt`; no image or
video media is present. The deployment note records a Reveal Pro 3.0 at the
Zipline Tower from 2025-08-07 to 2025-08-11. It says the camera was monitored
through the mobile app, buses triggered it rather than animals, and all captured
photos contained people and were not uploaded.

## Release Decision

The people-only deployment is excluded from the released Darwin Core data. The
current corrected snapshot has zero TW07-CT05 Event rows and zero Occurrence
rows. This avoids distributing visitor imagery and prevents the omission from
being interpreted as a wildlife-negative deployment.

## Evidentiary Boundary

The archive demonstrates non-upload and non-retention in this project release.
It does not demonstrate whether any camera-card images were subsequently
deleted. Release and manuscript text must not make a deletion claim without
owner confirmation.
