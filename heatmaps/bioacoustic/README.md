# Bioacoustic Sensor Heat Maps

This directory contains code for generating heat maps of animal density from bioacoustic sensor data.

## Branch Workflow
Work on bioacoustic heat maps should be done in the `bioacoustic-heatmaps` branch.

## Data Sources
- Audio recordings from bioacoustic sensors at The Wilds Summer 2025

## Analysis Goals
- Generate spatial density heat maps based on acoustic detections
- Identify vocalization hotspots
- Correlate acoustic activity with animal presence
