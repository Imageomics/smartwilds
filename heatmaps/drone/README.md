# Drone Sensor Heat Maps

This directory contains code for generating heat maps of animal density from drone imagery data.

## Branch Workflow
Work on drone heat maps should be done in the `drone-heatmaps` branch.

## Data Sources
- Aerial imagery collected via drones at The Wilds Summer 2025

## Analysis Goals
- Generate spatial density heat maps from aerial observations
- Cover larger geographic areas
- Identify herd patterns and movements
