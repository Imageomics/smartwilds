# Wildlife Detections CSV Format Documentation

## Overview

This document describes the format and structure of the `wildlife_detections.csv` file generated by the wildlife detection pipeline. The pipeline uses MegaDetector v5 for object detection and BioCLIP v2 for species identification.

## File Information

- **Filename**: `wildlife_detections.csv`
- **Format**: Comma-separated values (CSV)
- **Encoding**: UTF-8
- **One row per**: Photo/image file

## Column Definitions

### Basic Identifiers

| Column Name | Data Type | Description | Example |
|------------|-----------|-------------|---------|
| `file_ID` | String | Unique filename of the photo | `3D96ED14-5C52-402E-BB5A-A8B62F973BEA_1_105_c.jpeg` |
| `recording/photo/frame` | String | Media type indicator (always "photo" for this dataset) | `photo` |

### Temporal and Spatial Information

| Column Name | Data Type | Description | Example | Notes |
|------------|-----------|-------------|---------|-------|
| `date_time` | DateTime | Date and time when photo was taken | `2025-08-04 09:03:36` | Extracted from photo metadata; may be `null` if unavailable |
| `location` | String | Location name where photo was taken | `TheWilds` | All photos in this dataset are from The Wilds |
| `Latitude` | Float | GPS latitude coordinate in decimal degrees | `39.8150` | May be `null` or `0.0` if GPS unavailable |
| `Longitude` | Float | GPS longitude coordinate in decimal degrees | `-81.7250` | May be `null` or `0.0` if GPS unavailable |

### Detection Counts 
(outputs from MegaDetector)

| Column Name | Data Type | Description | Range | Notes |
|------------|-----------|-------------|-------|-------|
| `num_animals` | Integer | Number of animals detected in the photo | 0-N | Detected by MegaDetector with confidence > 0.2 |
| `num_people` | Integer | Number of people detected in the photo | 0-N | Photos with people are typically filtered out |
| `num_vehicles` | Integer | Number of vehicles detected in the photo | 0-N | Includes cars, trucks, and other vehicles |

### Detection Flags

| Column Name | Data Type | Description | Values |
|------------|-----------|-------------|--------|
| `contains_animals` | Boolean | Whether any animals were detected | `True` or `False` |
| `contains_people` | Boolean | Whether any people were detected | `True` or `False` |

### Bounding Box Annotations

| Column Name | Data Type | Description | Format | Example |
|------------|-----------|-------------|--------|---------|
| `animal_bounding_boxes` | String | Coordinates of bounding boxes for all detected animals | `animal_N: [x, y, width, height]; ...` | `animal_1: [0.4945, 0.5337, 0.1033, 0.0675]; animal_2: [0.4056, 0.5451, 0.0742, 0.0430]` |

**Bounding Box Format Details:**
- Coordinates are normalized (range: 0.0 to 1.0)
- Format: `[x, y, width, height]`
  - `x`: Left edge position (0 = left side of image, 1 = right side)
  - `y`: Top edge position (0 = top of image, 1 = bottom)
  - `width`: Width of bounding box
  - `height`: Height of bounding box
- Multiple animals separated by semicolons (`;`)
- Empty string if no animals detected

**Converting to Pixel Coordinates:**
```python
# To convert normalized coordinates to pixels:
image_width = 1920  # actual image width in pixels
image_height = 1080  # actual image height in pixels

x_pixels = x * image_width
y_pixels = y * image_height
width_pixels = width * image_width
height_pixels = height * image_height
```

### Species Identification

| Column Name | Data Type | Description | Example | Notes |
|------------|-----------|-------------|---------|-------|
| `species_counts` | Dictionary/JSON | Dictionary of detected species and their counts | `{"Grevy's zebra": 2, "Scimitar-horned oryx": 1}` | Empty `{}` if no animals identified |
| `species_detected` | String | Human-readable list of species | `Grevy's zebra: 2, Scimitar-horned oryx: 1` | Empty string if no animals identified |
| `num_unique_species` | Integer | Number of different species detected | `0-N` | `0` if no animals or species ID failed |
| `total_animals_identified` | Integer | Total number of animals with species ID | `0-N` | May differ from `num_animals` if some detections couldn't be classified |
| `avg_species_confidence` | Float | Average confidence score for species predictions | `0.0-1.0` | `0.0` if no species identified; higher is better |

## Data Processing Pipeline

1. **Object Detection** (MegaDetector v5)
   - Detects animals, people, and vehicles
   - Confidence threshold: 0.2 (20%)
   - Returns bounding box coordinates for each detection

2. **Species Identification** (BioCLIP v2)
   - Crops each animal detection
   - Classifies against predefined species list
   - Returns top species prediction with confidence score

3. **Metadata Integration**
   - Matches photos with metadata from `photo_metadata.csv`
   - Extracts date/time, GPS coordinates from photo EXIF or Google Takeout JSON

## Usage Examples

### Python - Reading the CSV

```python
import pandas as pd

# Load the CSV
df = pd.read_csv('wildlife_detections.csv')

# Filter for photos with animals
animal_photos = df[df['contains_animals'] == True]

# Get photos with specific species
zebra_photos = df[df['species_detected'].str.contains("Grevy's zebra", na=False)]

# Calculate statistics
print(f"Total photos: {len(df)}")
print(f"Photos with animals: {animal_photos.shape[0]}")
print(f"Average animals per photo: {df['num_animals'].mean():.2f}")
```

### Python - Parsing Bounding Boxes

```python
import re

def parse_bounding_boxes(bbox_string):
    """Parse bounding box string into list of coordinates."""
    if not bbox_string or pd.isna(bbox_string):
        return []

    # Extract all bounding boxes
    pattern = r'animal_\d+: \[([\d.]+), ([\d.]+), ([\d.]+), ([\d.]+)\]'
    matches = re.findall(pattern, bbox_string)

    return [
        {
            'x': float(m[0]),
            'y': float(m[1]),
            'width': float(m[2]),
            'height': float(m[3])
        }
        for m in matches
    ]

# Example usage
bbox_str = df.iloc[0]['animal_bounding_boxes']
bboxes = parse_bounding_boxes(bbox_str)
print(f"Found {len(bboxes)} animals")
```

### R - Reading the CSV

```r
library(tidyverse)

# Load the CSV
df <- read_csv('wildlife_detections.csv')

# Filter for photos with animals
animal_photos <- df %>%
  filter(contains_animals == TRUE)

# Group by species
species_summary <- df %>%
  filter(num_unique_species > 0) %>%
  group_by(species_detected) %>%
  summarize(count = n())

print(species_summary)
```

## Data Quality Notes

### GPS Coordinates
- Many photos may have GPS coordinates of `0.0, 0.0` or `null` if:
  - Location services were disabled
  - Photo was taken indoors
  - Metadata was stripped during processing

### Species Identification
- `avg_species_confidence` values above 0.8 are generally reliable
- Lower confidence scores (< 0.5) should be manually reviewed
- Some detections may not receive species classification if:
  - Animal is too far away or obscured
  - Detection is a false positive
  - Species is not in the predefined list

### Bounding Boxes
- Bounding boxes may overlap if animals are close together
- Very small bounding boxes (width/height < 0.05) may be partial detections
- Boxes near image edges may be truncated
